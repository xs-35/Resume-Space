## 📖 نظرة عامة

**مساحة السيرة** تطبيق ويب عربي (RTL) يعالج السيرة الذاتية عبر سلسلة من الخطوات الآلية:

1. رفع ملف (PDF / DOCX / صور / TXT) واستخراج النص عبر OCR أو قارئات PDF/Mammoth
2. تفريغ البيانات: الاسم، المسمى الوظيفي، المهارات، الإنجازات الرقمية، بيانات التواصل، اللغات، الشهادات
3. مقارنة السيرة بالوصف الوظيفي المستهدف وحساب نسبة توافق في نطاق 80%–90%
4. توليد خمس مخرجات دفعة واحدة (سيرة ATS، نسخة معدّلة، نبذة LinkedIn، خطاب تعريفي، أسئلة مقابلة)
5. تصميم السيرة النهائية بأربعة قوالب ATS وتحميلها كـ PDF أو Word أو HTML

## ✨ الميزات

### 📄 استخراج ذكي من ملفات متعددة
- **PDF**: استخراج النص الأصلي، ومع تحوّل تلقائي لـ OCR إذا كان الملف صورة ممسوحة
- **DOCX**: قراءة كاملة عبر Mammoth.js
- **صور (PNG/JPG)**: OCR عربي + إنجليزي عبر Tesseract.js مع معالجة مسبقة (رفع تباين، تحويل لتدرج رمادي، تصغير ذكي للحد الأقصى 2200px)
- **TXT**: قراءة مباشرة
- **حد أقصى**: 10 ميجابايت لكل ملف

### 🧬 كشف بيانات دقيق
- **الاسم الكامل**: مستخرج من السطور الأولى، أو من البريد الإلكتروني، أو من رابط LinkedIn
- **المسمى الوظيفي**: من مكتبة 21 دوراً مهنياً
- **المهارات**: أكثر من 80 مهارة (تقنية، إدارية، تصميم، بيانات، تسويق...)
- **الإنجازات الرقمية**: أسطر تحتوي نسباً مئوية أو أرقاماً أو مؤشرات أداء
- **سنوات الخبرة**: من عبارات مباشرة أو حساب فترات التواريخ
- **بيانات التواصل**: بريد، هاتف، LinkedIn، GitHub، موقع
- **اللغات والشهادات**: من الأقسام المخصصة

### 🎯 مطابقة الوصف الوظيفي
- استخراج مهارات الوظيفة تلقائياً من نص الوصف
- تحديد المهارات الناقصة التي يجب تغطيتها
- حساب نسبة توافق مضبوطة على النطاق 80%–90% (لأن السيرة المثالية لا يجب أن تظهر 100%)

### 🚀 خمسة مخرجات استراتيجية
| # | المخرج | الوصف |
|---|--------|-------|
| 1 | **سيرة ATS** | سيرة متوافقة مع أنظمة الفحص الآلي، بأفعال قوية وأرقام |
| 2 | **سيرة معدّلة للوظيفة** | نسخة موجهة للوصف الوظيفي مع خطة تغطية المهارات الناقصة |
| 3 | **نبذة LinkedIn** | 150–200 كلمة لتسويق الذات |
| 4 | **خطاب تعريفي** | 5 جمل مكثفة بأسلوب تنفيذي |
| 5 | **محاكاة مقابلة** | 10 أسئلة (تقنية، سلوكية، استراتيجية) مع تلميحات إجابة |

### ✎ مصمم سيرة بأربعة قوالب ATS
- **كلاسيكي**: محايد، آمن لأنظمة ATS القديمة
- **حديث**: خط جانبي بلون مميز، عناوين جريئة
- **تنفيذي**: رأس داكن فاخر بعرض كامل
- **نقي**: مساحات واسعة، خطوط رقيقة، تركيز على المحتوى

كل قالب يعمل مع **معاينة مباشرة** أثناء التحرير، وتنزيل مباشر بصيغ:
- **PDF** عبر حوار الطباعة بتنسيق A4 محسّن
- **HTML** ملف مستقل
- **Word (.doc)** متوافق مع Word و Google Docs


### 🌓 تجربة استخدام كاملة
- **وضع ليلي/نهاري** محفوظ في المتصفح
- **جولة تعريفية** من 6 خطوات عند أول زيارة (قابلة للتخطي وإعادة العرض)
- **حفظ تلقائي للجلسة**: عند العودة للصفحة تُستعاد آخر سيرة ونتائج
- **تخزين مؤقت لنتائج OCR**: رفع نفس الملف مجدداً لا يستغرق وقتاً
- **تصميم RTL** كامل مع خطوط عربية احترافية (Noto Naskh + IBM Plex Sans Arabic)

## 🛠️ التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| **الواجهة** | HTML5, CSS3 (Custom Properties, color-mix, backdrop-filter), Vanilla JavaScript (ES2020+) |
| **الخطوط** | Google Fonts: Noto Naskh Arabic, IBM Plex Sans Arabic, JetBrains Mono |
| **OCR** | Tesseract.js v5 (ara+eng) — يُحمَّل عند الحاجة فقط |
| **PDF** | PDF.js v3.11 (قراءة) + طباعة المتصفح (كتابة) |
| **DOCX** | Mammoth.js v1.6 |
| **التخزين** | localStorage (لا خادم، لا قاعدة بيانات، لا حساب) |

**لا يوجد**:
- ❌ إطار عمل (React/Vue) — Vanilla JS خالص
- ❌ خادم أو API — كل شيء في المتصفح
- ❌ تتبع أو تحليلات
- ❌ رفع ملفات لأي مكان
